# Launchixis

Launch operations for Apixis-family companies. One company at a time.

Live product is the launch board (checklist persisted in this company's Supabase) at https://launchixis.vercel.app. Not a coming-soon page.

Family chrome: A Apixis Company.

Family locks: every signup gets its own Apixis world agent via Apixis ID (`https://www.apixis.dev/enter?from=launchixis`); payments only via Apixis Wallet (pricing in Ixis, no Launchixis Stripe); Apixis Bank takes 5% of every Apixis-universe transaction, including agent-to-agent deals.

Current status, bugs, and keys: see `docs/LAUNCH_NOTES.md`.
