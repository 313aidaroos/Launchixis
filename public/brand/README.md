# Launchixis studio artwork

- `launchixis.png`: transparent PNG based on the owner's supplied rainbow Launchixis logo (`IMG_2704.PNG`). Background removal/reconstruction used image generation; resized for the sidebar with alpha preserved.
- `cixy-studio.webp`: generated art-only studio background following the approved Cixy design: recognizable brunette updo, purple blazer, midnight blue studio and cyan/pink light arches, with clear space for live HTML text.
- `cixy-avatar.webp`: existing Cixy portrait from the owner's Socixis repository (`socixis-app/public/cixy/cixy-combo-a-avatar.webp`).

All text, navigation, cards, checklists and controls are rendered as accessible HTML. Existing company images in `public/companies` remain unchanged.
